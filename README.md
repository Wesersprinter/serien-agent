# Serien-Agent

Wöchentlicher Serien-Report für Henning. Eine Cloud-Routine klont dieses Repo jeden
Freitag, liest das Profil, recherchiert neue Serienstarts im Web, legt den Report
unter `reports/` ab, schreibt die Historie fort und committet alles zurück.

| Datei | Zweck |
|---|---|
| `serien-profil.md` | Geschmack, Dienste, Lieblingsserien — **hier bearbeitest du dein Profil** |
| `AGENT.md` | Arbeitsanweisung für jeden Lauf |
| `historie.md` | Bereits vorgeschlagene Titel + dein Feedback |
| `reports/` | Ein Report pro Lauf |

## Wie du Einfluss nimmst

1. **Profil ändern:** `serien-profil.md` bearbeiten, committen, pushen. Der nächste
   Lauf richtet sich danach — kein Umweg über den Routine-Prompt mehr.
2. **Feedback geben:** In `historie.md` unter "Feedback" eine Zeile schreiben,
   etwa `- Pendragon Cycle — das war nichts — zu brav inszeniert`. Der nächste Lauf
   arbeitet es ins Profil ein.

Routine: "Serien-Wochenreport (Henning)", Freitag 09:00 Europe/Berlin,
zu sehen unter https://claude.ai/code/routines
